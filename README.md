# cinf505-data-management-analysis-platform
Author: Kaleena Li
Instructor: Professor Cheng

Project Description 
Messy data is not helpful for student's research. This project provides a platform to help them clean, organize, and visualize data to get meaningful results. A student can import a CSV or Excel file, check it for missing values, duplicates, and inconsistent entries, clean it, run basic analyses (summary statistics, correlation, group comparison), create charts, and export the result. The original data is never changed; all cleaning is done on a copy, and the user chooses every fix. The project also lets me learn how tools like Excel and Power BI process data by building these functions in code.

Technologies:
- Python 3
- Streamlit (web interface)
- Pandas and NumPy (data cleaning and analysis)
- Matplotlib and Seaborn (visualizations)
- SQLAlchemy and SQLite (data storage)
- openpycl (import and expore excel)
